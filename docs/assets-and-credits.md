## Before Reusing or Redistributing Media

Confirm the creator, original source, and terms for each item. For generated assets, retain the provider/model and generation records and check applicable provider terms. For recordings, also verify the rights to every included image, video, music track, and sound effect. No specific music source has been confirmed from the available project metadata.

If permission cannot be established, replace or remove the relevant material. This document records an unresolved provenance gap; it does not resolve it or certify that public redistribution is authorized. Code licensing does not cover that gap.

To complete this inventory, add the source URL, creator, license or written permission, and any required attribution for each verified asset. Reports about asset ownership can be raised through the repository's GitHub contact channels.
